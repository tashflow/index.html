# Stak Suite

Single-file web app: **StockStak** (inventory & POS) + **SweetStak** (pastry orders).

## Live use
- Open `index.html` in a browser, or host on **GitHub Pages** / **Netlify**.
- Data is stored in the browser (localStorage). Optional **Firebase** cloud sync is built in.

## GitHub Pages
1. Upload this repo to GitHub.
2. **Settings → Pages → Deploy from branch** → `main` → `/ (root)`.
3. Site URL: `https://YOUR_USERNAME.github.io/REPO_NAME/`

## Firebase
Project: `stak-suite` (config is embedded). Enable **Firestore** in the Firebase Console for sync.
